# 🛡️ Segundo Cérebro — Cibersegurança

Projeto desenvolvido com o NotebookLM para organizar conhecimentos sobre cibersegurança, ataques cibernéticos e exploração de vulnerabilidades.

## 🎯 Objetivo

Compreender como funcionam os principais ataques cibernéticos, como vulnerabilidades são exploradas e quais técnicas podem ser utilizadas para prevenir esses ataques.

O foco está em três categorias do OWASP Top 10:2025:

- **A01:** Broken Access Control.
- **A02:** Security Misconfiguration.
- **A05:** Injection.

## 🧰 Ferramenta utilizada

**NotebookLM:** utilizado para reunir fontes, explorar conceitos, responder perguntas e gerar materiais de estudo.

## 📚 Fontes utilizadas

- [CERT.br — Cartilha de Segurança para Internet](https://cartilha.cert.br/)
- [CERT.br — Ransomware](https://www2.cert.br/docs/ransomware/)
- [OWASP Top 10:2025](https://top10.owasp.org/2025/pt-BR/)
- [OWASP A02:2025](https://top10.owasp.org/2025/pt-BR/A02_2025-Security_Misconfiguration/)
- [OWASP A05:2025](https://top10.owasp.org/2025/pt-BR/A05_2025-Injection/)
- OWASP A01:2025 — Broken Access Control.

## ⚙️ Instruções personalizadas

O NotebookLM foi configurado para atuar como tutor de cibersegurança, utilizando linguagem didática, explicações progressivas, exemplos práticos e citações das fontes adicionadas.

## 💬 Perguntas realizadas

- O que é cibersegurança e quais são as principais ameaças?
- O que são vulnerabilidades e como funcionam as categorias A01, A02 e A05?
- Quais são as formas de exploração e prevenção dessas vulnerabilidades?
- Como organizar os conhecimentos em um guia de estudos?
